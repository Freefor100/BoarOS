# 开发路线

本文供开发者跟踪尚未完成的工作。功能现状和试用入口见[项目主页](../README.md)，接口边界以[模块说明](README.md)为准。

## 多核与关键路径

- **共享地址空间。** 继续缩小固定地址替换、权限修改和文件装页中的共享范围。验证同一地址空间并发复制、撤映射、截断和退出时，页引用与远程地址转换失效的时序。[内存管理](modules/kernel-mm.md)
- **等待与调度。** 区分业务对象等待和唤醒后等待运行。针对独立对象负载，找出有期限等待、共享调度状态及跨核通知的实际成本。[调度](modules/kernel-scheduler.md)
- **文件与网络。** 分别观察缓存接纳、后台写回、日志提交与最终同步。网络侧按连接区分协议执行、端点及协议内存池争用。[文件系统](modules/vfs-ext4.md) · [网络](modules/kernel-network.md)

## 平台

VisionFive 2 和龙芯 2K1000LA 的实板验收单独推进，覆盖启动、内存、中断、设备访问、根盘和网络。虚拟机结果用于验证软件路径和定位，实板的设备时序、吞吐和掉电恢复由实测确定。
